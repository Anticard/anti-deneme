ANTI DİJİTAL UYGULAMA - GitHub Pages DEMO

1. config.js dosyasına resmi WhatsApp destek numaranızı yazın (örnek biçim: 905XXXXXXXXX).
2. ZIP içindeki TÜM dosyaları ve assets klasörünü GitHub deponuzun ana dizinine yükleyin.
3. Settings > Pages > Deploy from a branch > main > /(root) > Save.
4. Siteyi HTTPS üzerinden açın. Telefon tarayıcısında Ana Ekrana Ekle seçeneğini kullanın.

ÖNEMLİ: Bu paket gerçek bir üyelik sistemi değildir. Kayıt/giriş sadece aynı cihazda saklanan DEMO profildir. Şifre kaydedilmez ve doğrulanmaz. Gerçek kullanıcı kaydı, parola sıfırlama, sunucu veritabanı, yönetim paneli, push bildirim ve güvenli erişim için ayrıca backend (örn. Firebase/Supabase) ve KVKK uyumlu veri işleme altyapısı gerekir. GitHub Pages tek başına bunları sağlamaz.

WhatsApp numarası bilinmediğinden boş bırakılmıştır; numara girilene kadar buton bilgilendirme verir.
